GitOps와 ArgoCD 개요

📅 2024-10-15 noisonnoiton

Interactive Diagram

새 탭 ↗

개요

섹션 제목: “개요”

GitOps는 Git을 단일 진실 원천(Single Source of Truth)으로 삼아 애플리케이션과 인프라 상태를 선언적으로 관리하는 접근 방식이다. 006_gitops 시리즈가 실제 배포 파이프라인과 Flagger, Argo Workflow 같은 실전 운영 도구를 다뤘다면, 이 글은 조직 표준 아키텍처 문서에서 정리했던 개론 수준의 GitOps/ArgoCD 개념을 다룬다. 신규 팀에 GitOps를 소개할 때 쓰는 표준 자료라고 보면 된다.

핵심 개념

섹션 제목: “핵심 개념”
  1. 선언적 구성: 인프라와 애플리케이션의 상태를 YAML/JSON 같은 선언적 파일로 정의한다.
  2. Git을 단일 진실 원천으로 사용: 모든 구성 파일을 Git 리포지토리에 저장하고, 버전 관리 기능으로 변경 이력을 추적한다.
  3. 자동화된 동기화: Git 리포지토리 상태와 실제 클러스터 상태를 자동으로 동기화한다. 이를 위해 ArgoCD, Flux 같은 도구를 사용한다.
  4. 감사 및 롤백: Git 변경 이력을 통해 누가, 언제, 무엇을 변경했는지 추적할 수 있고, 필요 시 이전 상태로 롤백할 수 있다.

GitOps의 장점

섹션 제목: “GitOps의 장점”
  • 버전 관리: 모든 변경 사항이 Git에 기록되어 변경 이력을 쉽게 추적할 수 있다.
  • 자동화: 선언적 구성과 자동화된 동기화로 수동 작업을 줄이고 일관된 배포를 보장한다.
  • 협업: Git 기반 코드 리뷰와 승인 프로세스로 팀 간 협업이 쉬워진다.
  • 안정성: 선언적 구성과 자동 동기화로 인프라와 애플리케이션 상태를 일관되게 유지한다.

GitOps 워크플로우

섹션 제목: “GitOps 워크플로우”
  1. 구성 파일 작성: 애플리케이션 및 인프라의 선언적 구성 파일을 작성한다.
  2. Git 리포지토리에 커밋: 구성 파일을 Git 리포지토리에 커밋하고 푸시한다.
  3. 자동화 도구 설정: ArgoCD, Flux 같은 GitOps 도구로 Git 리포지토리와 클러스터를 동기화한다.
  4. 자동 동기화: GitOps 도구가 Git 리포지토리의 변경 사항을 감지하고 클러스터 상태를 자동으로 업데이트한다.
  5. 모니터링 및 롤백: 변경 사항을 모니터링하고, 필요 시 이전 상태로 롤백한다.

ArgoCD 아키텍처

섹션 제목: “ArgoCD 아키텍처”

ArgoCD는 Kubernetes 네이티브 GitOps 도구로, Git 리포지토리를 단일 진실 원천으로 사용해 Kubernetes 클러스터의 애플리케이션을 자동으로 배포하고 관리한다.

ArgoCD의 주요 구성 요소는 다음과 같다.

  • API 서버: ArgoCD의 핵심 API를 제공하며, 웹 UI와 CLI를 통해 상호작용한다.
  • 레포지토리 서버: Git 리포지토리와 상호작용해 애플리케이션의 선언적 구성을 가져온다.
  • 애플리케이션 컨트롤러: 애플리케이션 상태를 모니터링하고, Git 리포지토리와 Kubernetes 클러스터 간의 상태를 동기화한다.
  • Dex: SSO(Single Sign-On) 및 OAuth2 인증을 지원한다.
  • Notification 서버: 애플리케이션 상태 변경, 동기화 상태, 헬스 체크 결과 등의 이벤트에 대해 알림을 제공한다.
  • Redis: 캐싱 및 세션 관리를 담당해 성능을 향상시킨다.

주요 기능

섹션 제목: “주요 기능”
  • 자동 동기화: Git 리포지토리의 변경 사항을 감지하고, Kubernetes 클러스터 상태를 자동으로 업데이트한다.
  • 선언적 구성: 애플리케이션 상태를 YAML 또는 JSON 파일로 선언적으로 정의한다.
  • 웹 UI 및 CLI: 사용자 친화적인 웹 UI와 강력한 CLI를 제공한다.
  • RBAC: 역할 기반 접근 제어를 통해 사용자 권한을 관리한다.
  • 헬스 체크 및 롤백: 애플리케이션 상태를 모니터링하고, 필요 시 이전 상태로 롤백한다.
  • 다중 클러스터 지원: 여러 Kubernetes 클러스터를 관리할 수 있다.

요약

섹션 제목: “요약”

GitOps는 Git을 단일 진실 원천으로 사용해 애플리케이션과 인프라를 선언적으로 관리하는 접근 방식이다. ArgoCD는 API 서버, 레포지토리 서버, 애플리케이션 컨트롤러, Dex, Notification 서버, Redis라는 여섯 축의 구성 요소로 이 접근 방식을 구현하며, 자동 동기화·RBAC·다중 클러스터 지원 같은 기능을 통해 Kubernetes 애플리케이션의 배포와 운영을 효율화한다.
