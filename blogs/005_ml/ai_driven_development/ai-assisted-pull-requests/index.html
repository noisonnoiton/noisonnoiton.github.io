AI-assisted PR Note와 Code Review

📅 2025-08-03 noisonnoiton

Context Package로 만든 코드, 이제 PR로

섹션 제목: “Context Package로 만든 코드, 이제 PR로”

앞선 글에서 Context Package로 구현을 요청하면 Agent는 결정 요약, 변경 파일, 검증 명령, 실행 결과, 미확인 사항을 함께 보고한다. 이 다섯 가지는 사실 PR Note의 초안이나 다름없다. 이번 글에서는 이 산출물을 실제 PR 프로세스에 어떻게 연결하는지, 그리고 AI가 도와도 되는 지점과 반드시 사람이 남아야 하는 지점을 구분한다.

PR 프로세스 자체는 바뀌지 않는다

섹션 제목: “PR 프로세스 자체는 바뀌지 않는다”

AI를 도입한다고 해서 브랜치 생성 → 커밋 → PR 생성 → 리뷰 → 승인 → Merge라는 기본 흐름이 바뀌지는 않는다. 바뀌는 것은 이 흐름의 각 단계에서 사람이 처음부터 타이핑하는 텍스트 양이다.

AI가 실질적으로 도움이 되는 영역

섹션 제목: “AI가 실질적으로 도움이 되는 영역”

PR Note 초안 작성

섹션 제목: “PR Note 초안 작성”

커밋 히스토리와 코드 diff를 분석해 변경된 파일, 함수, 클래스 단위로 요약을 만드는 작업은 AI가 사람보다 빠르고 누락이 적다. 앞 글의 Context Package 출력 구조를 그대로 재사용하면 PR Note 초안은 다음과 같은 형태가 된다.

이 초안은 사람이 처음부터 작성하는 것보다 빠르지만, Open Items가 비어 있으면 의심해야 한다는 원칙은 여기서도 동일하게 적용된다.

기계적으로 확인 가능한 리뷰 항목

섹션 제목: “기계적으로 확인 가능한 리뷰 항목”

AI가 신뢰성 있게 잡아낼 수 있는 리뷰 항목은 대체로 규칙이 명확하고 정답이 하나인 것들이다.

이 항목들은 정답이 명확하기 때문에 AI가 먼저 걸러주면, 사람 리뷰어는 “이 코드가 우리 비즈니스 로직에 맞는가”라는, AI가 답할 수 없는 질문에 집중 시간을 더 쓸 수 있다.

사람이 반드시 남아야 하는 영역

섹션 제목: “사람이 반드시 남아야 하는 영역”

Business 정합성 승인

섹션 제목: “Business 정합성 승인”

“이 코드가 문법적으로 올바르고 테스트를 통과한다”와 “이 코드가 우리가 원하는 비즈니스 요구를 실제로 충족한다”는 별개의 질문이다. 후자는 이 시리즈 2편에서 만든 PRD·User Story를 아는 사람만 판단할 수 있다. AI는 Acceptance Criteria 문자열이 코드와 일치하는지는 확인할 수 있어도, 그 Acceptance Criteria 자체가 비즈니스적으로 맞는 결정이었는지는 판단할 수 없다.

Security 최종 판단

섹션 제목: “Security 최종 판단”

AI가 흔한 패턴의 보안 이슈를 잡아내는 것과, 이 프로젝트의 위협 모델에서 이 변경이 안전하다고 확정하는 것은 다른 일이다. 특히 다음 상황에서는 AI 리뷰 결과를 최종 판단으로 취급하면 안 된다.

이런 변경은 보안 담당자 또는 시니어 엔지니어의 명시적 승인 없이는 Merge하지 않는다는 규칙을 팀 차원에서 고정해야 한다.

Release 결정

섹션 제목: “Release 결정”

코드가 리뷰를 통과했다고 해서 지금 이 순간 배포해도 되는지는 또 다른 문제다. 배포 시점, 롤백 계획, 다른 배포와의 충돌 여부는 AI가 가진 정보(코드 diff)만으로는 판단할 수 없는, 운영 맥락에 속하는 결정이다.

AI 리뷰 도구를 팀에 도입할 때의 원칙

섹션 제목: “AI 리뷰 도구를 팀에 도입할 때의 원칙”

시리즈를 마치며

섹션 제목: “시리즈를 마치며”

요구사항에서 시작해 User Story, Context Package, Test Scenario를 거쳐 PR까지 — 이 시리즈는 하나의 요구사항이 Artifact Chain을 따라 어떻게 변환되는지, 그리고 각 단계에서 AI가 초안을 만들 수 있는 부분과 사람이 반드시 결정해야 하는 부분을 구분해왔다. 도구가 바뀌어도 이 원칙은 유효하다: 무엇을 AI에게 맡기든, 검증 기준을 먼저 만들고, Human Gate를 명시적으로 남긴다.
