AZ-305 Renewal Notes and 26 Practice Explanations

📅 2026-07-11 noisonnoiton

I successfully renewed AZ-305. This renewal felt less like a memorization exercise and more like a check on whether I could still explain, in one short sentence, why a specific Azure service is the right answer.

From a Microsoft Certified Trainer (MCT) perspective, renewal exams are really about clean service-selection criteria. That is why I wanted to keep this post as both a short retrospective and a reusable study note: a topic-based recap plus 26 representative question explanations.

This note was organized on 2026-07-11 (Sat) as a compact record of the renewal.

Renewal recap in one page

Section titled “Renewal recap in one page”
  • AZ-305 still focuses on architecture decision making.
  • Many questions are solved by identifying one or two decisive constraints.
  • Similar-looking services are separated by operational model, scale pattern, performance profile, or connectivity model.
  • As an MCT, it mattered more to summarize the answer in a teachable sentence than to simply get it right.

Topic-based condensed notes

Section titled “Topic-based condensed notes”

Data and storage

Section titled “Data and storage”
  • Cosmos DB for Table stands out when you need global distribution and multi-region replication.
  • Azure SQL Managed Instance is the answer when SQL Server compatibility matters.
  • Business Critical is for faster recovery and higher performance.
  • Hyperscale is for very large Azure SQL databases.
  • Azure Files Premium is the SSD-backed file share option.
  • Blob Storage + Key Vault is the classic pattern when you need both large-scale storage and customer-managed keys.

Networking and connectivity

Section titled “Networking and connectivity”
  • ExpressRoute is the default answer for low-latency dedicated connectivity from on-premises to Azure.
  • Azure Front Door is the global HTTP entry point with latency-based routing.
  • Azure Bastion provides secure RDP/SSH access without exposing VMs with public IPs.
  • NAT Gateway is the standard answer for subnet-level outbound internet connectivity.
  • A VNet is regional, and that fact is tested often.

Applications and integration

Section titled “Applications and integration”
  • App Service is frequently the answer when the goal is to reduce web app operational overhead.
  • Azure Functions fits low-volume, event-driven, or lightweight HTTP workloads.
  • Azure Files is the shared persistent storage answer for multiple containers.
  • Service Bus fits enterprise messaging, reliability, and auditability.
  • Event Grid fits event notification patterns.

Analytics and data platform

Section titled “Analytics and data platform”
  • Stream Analytics appears in real-time stream processing and anomaly detection questions.
  • Synapse Link is the Cosmos DB analytics answer when ETL should be minimized.
  • Databricks is the managed Spark answer.
  • Blob Storage remains the cost-efficient landing zone for large raw event data.

Security and data protection

Section titled “Security and data protection”
  • Dynamic Data Masking masks query results.
  • TDE encrypts data at rest.
  • TLS protects data in transit.
  • These are commonly mixed in questions, so the intent must be separated clearly.

26 representative practice explanations

Section titled “26 representative practice explanations”

Azure Table Storage vs Cosmos DB for Table

Section titled “Azure Table Storage vs Cosmos DB for Table”

Question 01

  • Question type: When should Azure Cosmos DB for Table be chosen over Azure Table Storage?
  • Answer: Multiple secondary replicas
  • Why: Cosmos DB for Table supports globally distributed replication scenarios. Azure Table Storage offers table storage capabilities, but not the same style of multi-region architecture.
  • Remember: Multi-region replication usually points to Cosmos DB.

Azure SQL Server Agent support

Section titled “Azure SQL Server Agent support”

Question 02

  • Question type: You are moving an on-premises SQL Server workload to Azure and you need SQL Server Agent.
  • Answer: Azure SQL Managed Instance
  • Why: Azure SQL Database does not support SQL Server Agent. Managed Instance is the closer compatibility choice.
  • Remember: Need SQL Server Agent → Managed Instance.

Azure SQL Database recovery time

Section titled “Azure SQL Database recovery time”

Question 03

  • Question type: Which Azure SQL Database tier provides the fastest recovery time?
  • Answer: Business Critical
  • Why: Business Critical uses a high-performance architecture with local SSD and fast failover behavior.
  • Remember: Fast recovery and high performance → Business Critical.

Dynamic Data Masking

Section titled “Dynamic Data Masking”

Question 04

  • Question type: Unauthorized users must not see full credit card numbers.
  • Answer: Dynamic Data Masking
  • Why: DDM masks query results for unauthorized users. It is not data-at-rest encryption.
  • Remember: Query masking → DDM, data at rest → TDE, in transit → TLS.

Azure Files Premium tier

Section titled “Azure Files Premium tier”

Question 05

  • Question type: You need SSD-backed Azure Files for a transaction-heavy workload.
  • Answer: Premium
  • Why: Premium Azure Files is SSD-based, unlike the standard tiers.
  • Remember: SSD-backed Azure Files → Premium.

Blob Storage customer-managed key

Section titled “Blob Storage customer-managed key”

Question 06

  • Question type: Blob data must be encrypted with a customer-managed key.
  • Answer: Azure Key Vault
  • Why: Customer-managed keys are stored in Key Vault and used by the storage service.
  • Remember: CMK almost always points to Key Vault.

VM data disk choice

Section titled “VM data disk choice”

Question 07

  • Question type: A development VM needs 6000 IOPS, 750 MB/s, and the lowest reasonable cost.
  • Answer: Premium SSD
  • Why: Standard disks are too slow and Ultra Disk is usually more expensive than necessary.
  • Remember: Balanced performance and cost → Premium SSD.

Azure SQL 100 TB database

Section titled “Azure SQL 100 TB database”

Question 08

  • Question type: You need to support a 100 TB Azure SQL database.
  • Answer: Hyperscale
  • Why: Hyperscale is built for very large database sizes and scale requirements.
  • Remember: Very large Azure SQL database → Hyperscale.

On-premises to Azure connectivity

Section titled “On-premises to Azure connectivity”

Question 09

  • Question type: You must minimize latency between the datacenter and an Azure VNet.
  • Answer: ExpressRoute
  • Why: ExpressRoute provides dedicated private connectivity instead of internet-based transport.
  • Remember: Lowest latency dedicated connectivity → ExpressRoute.

Multi-region web application

Section titled “Multi-region web application”

Question 10

  • Question type: You need a single hostname, HTTP load balancing, and lowest-latency routing.
  • Answer: Azure Front Door
  • Why: Front Door is Azure’s global Layer 7 HTTP load balancer.
  • Remember: Global web routing → Front Door.

PHP web app migration

Section titled “PHP web app migration”

Question 11

  • Question type: You want to migrate a PHP web app with minimal operational overhead.
  • Answer: Azure App Service
  • Why: App Service is the PaaS answer for managed web hosting without VM-level OS administration.
  • Remember: Web app plus minimal ops → App Service.

Container instance shared storage

Section titled “Container instance shared storage”

Question 12

  • Question type: Two containers need the same persistent shared storage.
  • Answer: Azure Files
  • Why: Azure Files provides a shared file system that multiple containers or instances can mount.
  • Remember: Shared persistent storage → Azure Files.

Serverless HTTP calculation

Section titled “Serverless HTTP calculation”

Question 13

  • Question type: You need a small HTTP-based code path with low request volume and minimal cost.
  • Answer: Azure Functions
  • Why: Consumption-based Functions are cost-efficient for intermittent workloads.
  • Remember: Intermittent HTTP code execution → Functions.

IoT upload event notification

Section titled “IoT upload event notification”

Question 14

  • Question type: You need notifications whenever a new file or music object is uploaded.
  • Answer: Azure Event Grid
  • Why: Event Grid is optimized for publishing and routing event notifications.
  • Remember: Event notification pattern → Event Grid.

Event Hub data storage

Section titled “Event Hub data storage”

Question 15

  • Question type: You need the lowest-cost storage for sensor data.
  • Answer: Azure Blob Storage
  • Why: Blob Storage is a cost-efficient landing zone for large volumes of raw event data.
  • Remember: Large cheap storage → Blob Storage.

API Management API count

Section titled “API Management API count”

Question 16

  • Question type: App1 has 30 APIs and App2 has 40 APIs. How many APIs are managed in total?
  • Answer: 70
  • Why: The count is based on APIs, not on backend servers.
  • Remember: 30 + 40 = 70.

Messaging and audit trail

Section titled “Messaging and audit trail”

Question 17

  • Question type: You need to retain more than 90 GB of messages and support auditing.
  • Answer: Azure Service Bus Queues
  • Why: Service Bus fits enterprise messaging scenarios with stronger control and tracking.
  • Remember: Auditable enterprise messaging → Service Bus.

Virtual Network count

Section titled “Virtual Network count”

Question 18

  • Question type: You deploy in East US and West US. How many VNets are required?
  • Answer: 2
  • Why: A VNet is scoped to a region.
  • Remember: Number of regions = minimum number of VNets.

Azure Bastion

Section titled “Azure Bastion”

Question 19

  • Question type: You need RDP access but want to minimize direct internet exposure.
  • Answer: Azure Bastion
  • Why: Bastion gives browser-based RDP/SSH access without assigning public IPs to the VMs.
  • Remember: Secure admin access → Bastion.

NAT Gateway

Section titled “NAT Gateway”

Question 20

  • Question type: Multiple VMs must share the same public IP pool for outbound connectivity.
  • Answer: NAT Gateway
  • Why: NAT Gateway provides subnet-level outbound internet access. It is not for inbound access.
  • Remember: Outbound only → NAT Gateway.

Branch office multi-region VNet

Section titled “Branch office multi-region VNet”

Question 21

  • Question type: You use five Azure regions. What is the minimum number of VNets?
  • Answer: 5
  • Why: Each region needs its own VNet.
  • Remember: Count the regions.

Cosmos DB near real-time analytics

Section titled “Cosmos DB near real-time analytics”

Question 22

  • Question type: You need to analyze Cosmos DB data in Synapse in near real time.
  • Answer: Synapse Link
  • Why: Synapse Link exposes Cosmos DB analytical access with minimal ETL.
  • Remember: Cosmos DB analytics path → Synapse Link.

IoT Hub anomaly detection

Section titled “IoT Hub anomaly detection”

Question 23

  • Question type: IoT Hub data must be analyzed for anomalies and visualized in Power BI.
  • Answer: Azure Stream Analytics
  • Why: Stream Analytics is the real-time streaming analysis service in this scenario.
  • Remember: IoT real-time analytics → Stream Analytics.

Apache Spark migration

Section titled “Apache Spark migration”

Question 24

  • Question type: You want to migrate on-premises Spark workloads to a managed Spark service on Azure.
  • Answer: Azure Databricks
  • Why: Databricks is the best-known managed Spark platform on Azure.
  • Remember: Managed Spark → Databricks.

VM network design first step

Section titled “VM network design first step”

Question 25

  • Question type: What should be considered first when designing Azure VM infrastructure?
  • Answer: Azure Virtual Network settings
  • Why: Azure VMs are deployed into VNets and subnets, so networking is the starting point.
  • Remember: VM design begins with networking.

Subnet outbound connectivity

Section titled “Subnet outbound connectivity”

Question 26

  • Question type: Thirty VMs must share the same public IP pool and allow outbound connectivity only.
  • Answer: NAT Gateway
  • Why: NAT Gateway provides a clean subnet-level outbound model using public IP resources.
  • Remember: Standard outbound answer → NAT Gateway.

Closing note

Section titled “Closing note”

This AZ-305 renewal reminded me again that architecture exams are not about memorizing long product lists. They are about reading requirements and quickly identifying the decisive criteria.

I plan to keep building this MCT category with the same format: exam retrospectives, service comparisons, and reusable study notes that are easy to explain to someone else. Those are usually the notes that stay the longest.
